# 文献检索 Skill

## 触发条件
当任务涉及检索、筛选、核验论文清单、找最新研究时使用。只负责文献发现和初筛，不负责写综述。

## 输入
- research_question：研究问题（必需）
- date_range：时间范围，缺失时写明实际采用的范围
- max_results：目标篇数，默认 5；是上限，不是必须凑齐
- inclusion / exclusion：纳入和排除标准（有则遵守）
- destination：上游指定的输出位置（有则使用）

## 过程
1. 将研究问题拆成中英文关键词、同义词及必要限定词，记录实际查询式。
2. 使用当前可用的检索工具访问 PubMed、Europe PMC 或其他可信来源；只报告真正检索到的结果。
3. 每条记录逐项核验题名、年份、期刊、PMID/DOI 与链接的匹配性，必要时打开记录核查。
4. 去重，按与研究问题的相关性排序；不可为了凑数量编造论文。
5. 标记是否仅阅读题录/摘要，不能把摘要检索当作全文阅读。
6. 形成可供下游使用的文献清单，优先写入上游指定的可访问路径；如果无法共享文件，直接在任务结果中给出结构化清单。

## 输出契约
优先产出 `papers.json`（若文件可写），结构例如：
```json
{
  "question": "SIK2 靶点近三年的研究进展",
  "searched_at": "执行时真实日期",
  "queries": ["实际使用过的查询式"],
  "source_databases": ["实际使用过的数据库"],
  "papers": [
    {
      "title": "真实检索得到的论文题名",
      "year": 2025,
      "journal": "实际期刊",
      "doi": "经核验的 DOI，未知则 null",
      "pmid": "经核验的 PMID，未知则 null",
      "source_url": "实际记录链接",
      "abstract_available": true,
      "full_text_checked": false,
      "relevance_note": "与研究问题的关联",
      "verification": "verified 或 unverified"
    }
  ],
  "limitations": ["尚未获得的资料或检索限制"]
}
```
JSON 中每条记录必须来自实际检索结果。只有上游可访问时才报告文件路径；禁止捏造保存成功。

## 交接说明
向科研主管返回：检索了哪里、使用了什么查询式、真实找到多少篇、哪些文献被核验、结果存储位置或直接返回的清单、未解决问题。

## 禁止事项
- 不凭模型记忆伪造实时检索结果或引文。
- 不把 DOI 或来源链接与不匹配的文章绑定。
- 无法访问外部数据库时明确报告阻碍，不假装成功。
- 不执行未经请求的删除、覆盖或系统级操作。
